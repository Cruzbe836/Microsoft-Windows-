NAVEGADOR EDGE

 

 

Es el navegador web oficial de Microsoft, basado en la tecnología Chromium .

Ofrece navegación rápida, herramientas de inteligencia artificial integradas como Copilot, visor de PDF avanzado

y funciones de personalización para optimizar la productividad y la seguridad.

 

 

 

Desarrollado para sustituir al clásico Internet Explorer, este navegador multidispositivo se destaca por las siguientes características clave:

  • Inteligencia Artificial integrada: Cuenta con acceso directo a Copilot para resumir páginas web, extraer datos de documentos y responder dudas al instante.
  • Optimización de recursos: Incluye pestañas verticales, modo de pantalla dividida y "Workspaces" (áreas de trabajo) para una mejor organización.
  • Compatibilidad de extensiones: Al utilizar la misma base de Chromium que Google Chrome, permite instalar la gran mayoría de extensiones de la Chrome Web Store.
  • Privacidad y Seguridad: Ofrece protección de seguimiento integrada y el programa Microsoft Defender SmartScreen para bloquear sitios web y descargas maliciosas.

 

 

Características principales:

  • Inteligencia Artificial integrada: Incluye un botón directo para acceder a Copilot (la IA de Microsoft), que sirve para resumir artículos web largos, analizar documentos PDF y realizar preguntas sobre el contenido que estás viendo.
  • Compatible con complementos:Al basarse en Chromium, permite instalar casi todas las extensiones diseñadas para Google Chrome desde la tienda oficial.
  • Modo Niños: Ofrece un entorno protegido, con un diseño apto para los más pequeños y filtros web que bloquean contenido para adultos de forma automático.
  • Integración con Microsoft 365: Permite trabajar de forma paralela con documentos de Word, Excel y PowerPoint en la nube.
  • Rendimiento optimizado: Está diseñado para consumir menos memoria RAM que otros competidores directos en sistemas Windows.
